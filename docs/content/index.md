A small Go service for a static JAM stack site. It runs on Google Cloud Run and
currently provides double opt-in newsletter signup. It is designed to grow into
event signups and POSSE syndication (Bluesky, Mastodon).

## Context

Designed to support a Publish-on-Own-Servers-Syndicate-Elsewhere (POSSE) strategy.

- You don't redirect users to signup to newsletters or events. 
- You don't put your writings on LinkedIn, Medium or elsewhere.

POSSE is part of a digital sovereignty agenda, where you maintain ownership of content and data. It calls for features that you may not have in a typical static web site. This is a service that will help you in your POSSE endeavors.
